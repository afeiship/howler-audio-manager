# howler-audio-manager
> Howler.js audio manager, enum-driven sounds for H5.

[![version][version-image]][version-url]
[![license][license-image]][license-url]
[![download][download-image]][download-url]

## installation
```shell
yarn add @jswork/howler-audio-manager
```

## usage
```js
import HowlerAudioManager from '@jswork/howler-audio-manager';

HowlerAudioManager(1024);

// [1000, 0, 20, 4]
```
